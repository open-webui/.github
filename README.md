# Open WebUI Community Health Files

## About This Repository

This is a special repository used to manage community health and configuration files for the entire **Open WebUI** organization on GitHub.

The files and configurations defined here provide defaults for all other repositories under our organization, ensuring a consistent and welcoming environment for our community.

### What's Inside?

* **`profile/README.md`**: This file contains the content for our main organization profile page, which you can see at [github.com/open-webui](https://github.com/open-webui).

* **`CONTRIBUTING.md`**: Our central guide for new and existing contributors. It outlines the general process for contributing to any of our projects.

* **`CODE_OF_CONDUCT.md`**: The code of conduct that applies to all our community spaces, ensuring a safe and respectful environment for everyone.

* **`SECURITY.md`**: Provides instructions on how to responsibly report security vulnerabilities you might find in our projects.

To explore the main Open WebUI application, please visit our primary repository at [**open-webui/open-webui**](https://github.com/open-webui/open-webui).
