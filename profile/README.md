# Welcome to Open WebUI 👋

![Open WebUI Demo](./demo.gif)

**Open WebUI is an [extensible](https://docs.openwebui.com/features/plugin/), feature-rich, and user-friendly self-hosted AI platform designed to operate entirely offline.** It supports various LLM runners like **Ollama** and **OpenAI-compatible APIs**, making it a powerful and versatile AI deployment solution.

Our goal is to build the best open-source user interface for AI.
